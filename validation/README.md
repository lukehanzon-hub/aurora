# Validation

Reference datasets and the harness that compares AURORA output against published data.
Rules (see CLAUDE.md "Validation"):

- Only openly available, original NACA/NASA (US-government public-domain) reports.
  Do not commit RASAero charts or images; cite and link them.
- One CSV per dataset with a header block: citation, report number, page/figure/table,
  Reynolds number and test conditions, units, and digitization method and uncertainty.
- Only use data at Mach 5 and below.
