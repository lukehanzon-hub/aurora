# AURORA

AURORA is a cross-platform rocket flight simulator written in Rust. It covers every phase
of flight (rail departure, boost, coast, staging, apogee, and recovery), supports multistage
vehicles and active control, and models aerodynamics from subsonic speeds up to Mach 5 using
engineering methods taken from the published NACA/NASA literature, each with a stated
validity envelope.
